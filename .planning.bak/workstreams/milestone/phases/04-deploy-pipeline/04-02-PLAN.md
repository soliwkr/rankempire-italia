  <action>
    Eseguire i seguenti passi manualmente:

    **Step 1 — Localizza il template Astro esistente.**
    Il template si chiama `astro-rank-rent` (o simile) nel tuo filesystem locale. Verificare la presenza di:
    - `astro.config.mjs`
    - `package.json` con `"build": "astro build"`
    - `src/data/site.config.json` (se non esiste, crearlo con contenuto placeholder: `{}`)

    Se il template non è ancora su GitHub:

    **Step 2 — Crea il repo su GitHub.**
    ```bash
    gh repo create StudioPuraLuce/astro-rank-rent --private --description "Rank & Rent Astro site template"
    ```

    **Step 3 — Push del template.**
    Dalla directory del template Astro locale:
    ```bash
    git init
    git add .
    git commit -m "chore: initial Astro rank-rent template"
    git remote add origin https://github.com/StudioPuraLuce/astro-rank-rent.git
    git push -u origin main
    ```

    **Step 4 — Abilita Template Repository flag.**
    Andare su: https://github.com/StudioPuraLuce/astro-rank-rent/settings

    **Step 5 — Verifica via API.**
    ```bash
    curl -s -H "Authorization: Bearer $GITHUB_TOKEN" \
      https://api.github.com/repos/StudioPuraLuce/astro-rank-rent | jq '.is_template'
    ```
    Deve restituire `true`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GITHUB_TOKEN (locale) → GitHub API | Token con scope repo usato per push e verifica — non deve trapelare in log CI/CD |
| Template repo (pubblico/privato) | Il repo è privato per ora — se diventasse pubblico, site.config.json placeholder non deve contenere secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Information Disclosure | GITHUB_TOKEN in shell history | accept | Token usato solo in comandi locali. `.env` non committato. Rischio basso: token locale sviluppatore |
| T-04-02-02 | Spoofing | Template repository errato | mitigate | Acceptance criteria verifica via GitHub API che `is_template: true` e il nome repo sia esatto `astro-rank-rent` sotto `StudioPuraLuce` — nessun ambiguità possibile |
| T-04-02-03 | Information Disclosure | site.config.json placeholder nel template | mitigate | Il placeholder deve contenere solo `{}` o campi null — mai API keys o secrets reali nel file committato nel template |
</threat_model>
